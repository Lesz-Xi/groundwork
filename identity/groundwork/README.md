# Groundwork identity

The open geometric G with an orange returning stroke names the guide's read → apply → return loop. It is original vector artwork authored in Paper, not a scientific-effectiveness claim.

- `groundwork-mark.svg`: ink/orange on light surfaces.
- `groundwork-mark-inverse.svg`: light/orange on ink.
- `groundwork-mark-mono.svg`: single-color variant.

Each SVG uses two vector paths, a 96×96 viewBox and no fonts, remote assets or raster dependency. The builder verifies pinned hashes in `provenance.json` before embedding the header/index placements. External SVG files are source/reuse assets; opening the HTML does not depend on them.

Private authoring-workspace links and historical preview assets are not published. Name/trademark availability has not been independently verified. The original artwork is covered by the repository's [MIT License](../../LICENSE); this does not convey trademark rights.
